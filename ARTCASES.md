# Арт-обложки v3 — 07.09.2026

Никита утвердил арт-обложки и перенос на GitHub Pages. Блок содержит
25 кейсов: первые 10 открыты, далее порции по 5. Карточки без стрелок,
номеров и всплывающих описаний. Без JavaScript доступны все 25.

- `sections/v3-artcases.html` — статичная разметка карточек.
- `assets/css/sections/v3-artcases.css` — стили с префиксом `artcases__`.
- `assets/css/tokens.css` — токены обложек в отдельном блоке ARTCASES.
- `assets/js/sections/v3-artcases.js` — только раскрытие списка.
- `assets/img/artcases/` — оптимизированные WebP и один SVG робота;
  хэш в имени меняется вместе с изображением.
- `node build.mjs` — сборка; v1/v2 используют прежние секции.

Исходный просмотр и генератор экспорта находятся в проекте студии:
`05 Дизайн/Кейсы — варианты Codex 07.09/`. После правок локального
`template.html` / `refinements.css`: `python3 optimize.py`,
`python3 build.py`, затем `node export-site.cjs` при работающем
превью на 127.0.0.1:8768. Финальная сборка — в этой папке сайта.
`publish-review.py` — историческая одноразовая миграция, не запускать повторно.
