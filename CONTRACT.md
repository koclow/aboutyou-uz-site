# Контракт вёрстки — About You UZ

Обязателен для каждого, кто пишет код в этом репозитории (агенты и люди).
Цель: одна система, а не сто вариантов.

## Источник правды

1. **Макет** — артборды канваса в `../Канвас — рабочие файлы/`:
   - `Main.dc.html` — вся главная целиком, порядок актов и точные значения;
   - `CasesMonday.dc.html` — каталог кейсов;
   - `HowFlow1.dc.html`, `HowFlow2.dc.html`, `HowFlow3.dc.html` — три состояния
     блока «С чем вы приходите» (переключатель вкладок);
   - `AboutManifesto.dc.html` — манифест «О нас» + команда-строка;
   - `FinalStudiogram.dc.html` — акт «Заявка» (форма + бордовая плашка).
   Значения в артбордах (px, цвета, веса, межбуквенные) — снимать точно,
   на десктопе 1440 расхождений быть не должно.
2. **Токены** — `assets/css/tokens.css`. Единственное место, где живут hex,
   размеры шрифта, длительности и изинги. В секционных css — только `var()`.
   Нужного токена нет → добавить в tokens.css с комментарием, не хардкодить.
3. **База** — `assets/css/main.css` (nav, cta, hero, лента, направления,
   `.rise`-появление) и `assets/js/main.js` (observer, лента, фильтры).
   Не дублировать их функциональность.

## Архитектура файлов

- `index.html` — собирается интегратором, руками не трогать.
- Секции: `sections/<имя>.html` — фрагмент, начинается с `<section>` и им же
  кончается. Никаких `<html>/<head>/<body>`, никаких `<style>/<script>` инлайном.
- Стили секции: `assets/css/sections/<имя>.css`.
- Скрипт секции (если нужен): `assets/js/sections/<имя>.js` — IIFE, как main.js,
  без зависимостей и без модульного синтаксиса (грузится обычным `<script defer>`).
- Никаких библиотек, CDN и фреймворков. Ванильные HTML/CSS/JS.

## Правила кода

- Классы: `имясекции__элемент`, модификаторы `--мод`. Префикс секции обязателен.
- Русская типографика: «ёлочки», тире —, неразрывные где нужно.
- Семантика: заголовки актов `h2`, подзаголовки `h3`; кнопки `<button>`,
  ссылки `<a>`; форма — настоящие `<label>+<input>`.
- Появление при скролле: класс `rise` (база уже анимирует его через `.in`).
  Стагер — `style="transition-delay:…"` на элементе.
- Всякая анимация — только через токены `--dur-*`, `--ease*`, и обязательно
  выключается в `@media (prefers-reduced-motion:reduce)`.
- Адаптив: десктоп по макету 1440; ≤900px колонки складываются в столбец;
  схемы «Как работаем» на мобиле превращаются в вертикальный список узлов
  (сетка-подложка скрывается). Горизонтального скролла у body нет никогда.
- Картинки: `assets/img/...`, всегда `alt`, `loading="lazy"` ниже первого экрана.

## Анимационная система (дозировано = дорого)

- Один сильный приём на акт, не больше:
  hero — подъём фразы при загрузке (есть в базе);
  лента пруфов — бесконечный ход (есть);
  направления — заливка красным по ховеру (есть);
  каталог кейсов — параллакс колонок (разная скорость к скроллу) + точка у
  заголовка по ховеру; постер НЕ искажается, максимум scale 1.02;
  «С чем вы приходите» — смена схем по вкладкам: уход fade-down 200мс,
  приход fade-up 300мс `--ease`, узлы схемы входят стагером 40мс;
  манифест — обычный `rise`;
  заявка — обычный `rise`, кнопка использует `.cta` из базы.
- Жест-подчёркивание: маркерный штрих (толщина 9, `stroke-linecap:butt`,
  почти прямой с подъёмом ~5°) — рисуется stroke-dashoffset'ом при появлении
  (600мс), не в цикле. Два жеста на страницу максимум — уже заняты
  (кейсы-заголовок и манифест), новых не добавлять.

## Пользовательский ввод (правило студии)

Черновик формы «Заявка» хранится в localStorage при вводе и восстанавливается
при следующем открытии; поле никогда не очищается до подтверждённой отправки.
Бэкенда пока нет: сабмит — заглушка, кнопка ведёт себя честно (не пишет
«отправлено», пока отправки нет; пишет «примем через Telegram», см. секцию).

## Запрещено

- «Мой Петербург» и цифра «600 тыс. посетителей» — не упоминать нигде.
- Рукописные шрифты (Caveat и пр.) — жесты только SVG-штрихами.
- Новые цвета, тени, радиусы вне токенов. Радиусы вообще только у узлов схем (10px).
