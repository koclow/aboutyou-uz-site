## Запуск

```bash
cd "Сайт" && python3 -m http.server 8940
```

или через превью Claude Code (`.claude/launch.json`, конфигурация `site`).

## Структура

```
index.html            — единственная страница (пока)
assets/css/main.css   — вся система стилей (токены вкусовой рамки в шапке файла)
assets/js/main.js     — лента, шапка, фильтры, счётчики, появления
assets/img/           — кадры, логотип, фото кейсов
assets/video/reel.mp4 — шоурил 1152px, 6 МБ, saturation 0.9
```

## Что уже решено дизайном

- Красный `#E10600` (формула H 0±4 · S ≥ 95 · L 38–46 — см.
  `../Стилистика/Вкусовая рамка v1`), графит `#141312`, бумага `#F2EFE9`.
- Драматургия: графит (герой + направления) → бумага (каталог кейсов) →
  графит (о нас) → красный финал.
- Кнопки с hover-перспективой (игра из логотипа).
- Каталог кейсов: фильтры по направлениям, карточка = медиа + заголовок
  + цифра отдельным штампом; клик по направлению открывает каталог
  с фильтром.
- Анимации (по скиллу find-animation-opportunities, дозированно):
  счётчик цифр при появлении, вход карточек при фильтрации со стагером
  30 мс, `:active` на фильтрах. Отклонено: параллакс, письмо по буквам,
  FLIP — мотивировка в PROJECT_STATUS от 24.08.
