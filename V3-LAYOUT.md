- Общая ширина: токен --v3-content-max = 1920 px, единые поля --v3-inset.

## Мобильная схема привязана к странице

По запросу Никиты 07.09 добавлен `v3-how-scroll.js`. Только при ширине ≤719,
достаточной высоте экрана и обычном режиме движения: обёртка создаёт вертикальный
отрезок, CSS sticky держит выбранную схему под nav, положение страницы задаёт
scrollLeft. Есть название сценария, прогресс, пропуск к #about и клавиши.
При reduced motion или высоте <620 — прежний ручной горизонтальный скролл.
Для sticky на body используется overflow-x:clip; transform появления у секции
отключён, чтобы не смещать координаты закрепления. Три вкладки не переключаются
автоматически. Скрипт схемы посылает how:change после смены сценария.
